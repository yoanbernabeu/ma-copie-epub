# Sécurité

Pour signaler une faille de sécurité dans l'extension ou le site, **n'ouvrez pas d'issue publique**. Utilisez le signalement privé de GitHub : onglet *Security*, puis *Report a vulnerability*.

L'extension n'a accès qu'à `https://melenchon2027.fr/*`, ne demande aucune autre permission et n'envoie aucune donnée. Toute découverte qui contredirait ces garanties est prioritaire.
