# Contribuer

Merci de votre intérêt pour Ma copie EPUB.

## Issue d'abord, pas de pull request

Ce projet **n'accepte pas de pull requests** : elles sont fermées automatiquement. Tout passe par les **issues** :

1. Ouvrez une [issue](../../issues/new/choose) en choisissant le bon modèle (bug, génération qui échoue, idée).
2. Décrivez le problème ou la proposition. Le mainteneur en discute avec vous, puis l'implémente lui-même.

Pourquoi : le projet repose sur un cadre juridique précis (copie privée). Chaque changement doit être vérifié au regard de ce cadre, ce qui est plus simple quand une seule personne écrit le code.

## Règle absolue : aucun extrait du texte

Ne collez **jamais** d'extrait du programme dans une issue, un commentaire ou une capture d'écran : ni phrase, ni paragraphe, ni sommaire. Le dépôt ne doit contenir aucun contenu protégé, et les issues font partie du dépôt.

Pour signaler un problème de mise en forme, décrivez-le (« les listes du chapitre 3 de la partie 2 n'ont plus de puces ») et indiquez l'adresse de la page concernée sur melenchon2027.fr.

## Ce qui est hors sujet

- Demandes de diffusion du fichier EPUB, ou d'un serveur qui le fabriquerait à votre place : le projet distribue un outil, jamais le texte.
- Contournement de toute protection du site source.
- Débats politiques sur le contenu du programme.

## Sécurité

Pour signaler une faille de sécurité, voir [SECURITY.md](SECURITY.md).
